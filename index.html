SOBRE O PROJETO

Sobre este MVP

Protótipo acadêmico de desenvolvimento tecnológico.

Continuidade do cuidado fisioterapêutico

Este MVP demonstra uma proposta de plataforma digital com perfis fictícios de fisioterapeuta e paciente, planos de exercícios individualizados, registro de sintomas e consulta de dados meteorológicos.

Limites do protótipo

Os dados são armazenados no navegador. A troca de perfis é demonstrativa e não configura autenticação, autorização ou proteção de dados clínicos adequada para uso real. Não insira informações pessoais, prontuários ou dados reais de saúde.

A aplicação não realiza prescrições automáticas, não substitui o atendimento profissional e não foi validada clinicamente.

Dados demonstrativos

Você pode exportar um arquivo com os dados fictícios do navegador ou restaurar os exemplos iniciais. A exportação é local e não envia dados a um servidor.

Projeto acadêmico independente, sem representação de vínculo formal com o Hospital Universitário de Brasília.
